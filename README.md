# КТ №3 — Responsive Solutions

Адаптивная учебная страница на HTML и CSS по первому макету:
https://nicepage.com/html-templates/preview/responsive-solutions-1096380

## Запуск
Откройте index.html в браузере. Установка зависимостей не нужна.
Фотографии Nicepage/Freepik сохранены в assets. Шрифты Google Fonts загружаются через интернет.
SVG-иконки сохранены из исходного учебного макета; HTML и CSS написаны отдельно.

## Что использовано
- Семантические header, nav, main, section, article, footer.
- Flexbox: 3 колонки на компьютере, 2 до 991 px, 1 до 575 px.
- Медиазапросы, viewport, фоновые изображения, отступы, типографика.
- Мобильное меню на details/summary, без JavaScript.
- Все внутренние ссылки ведут на разделы этой страницы.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий kt3-responsive-solutions.
2. Загрузите файлы из этой папки в корень репозитория, включая index.html и style.css.
3. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save.
4. После завершения публикации скопируйте адрес сайта из Settings → Pages.
5. Сдайте две ссылки: на репозиторий и опубликованный сайт.

Изображения и дизайн принадлежат соответствующим правообладателям. Работа предназначена для учебной демонстрации вёрстки.
